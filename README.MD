Sobre o projeto

Este projeto consiste em um site desenvolvido como atividade em sala de aula, com o objetivo de apresentar curiosidades sobre diferentes temas do nosso cotidiano.
O site possui uma página inicial e páginas específicas com informações sobre carros, celulares, comidas, computadores e flores.

Objetivo

Compartilhar informações e curiosidades de forma simples e organizada, utilizando páginas HTML conectadas por um menu de navegação.

Tecnologias utilizadas

HTML5
CSS3
